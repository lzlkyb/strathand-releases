# 策手 StratHand · 更新分发点

本仓库**只托管自动更新所需的产物**：`updater.json` 与各版本安装包。**不含任何源码、文档或用户数据。**

## 为什么单独一个仓库

策手的源码与规划文档在私有仓库。但 GitHub 私有仓库的 Release 附件需要认证才能下载，
桌面端 updater 无法匿名拉取（把 token 塞进 App 是不可接受的）。
因此拆出这个公开仓库专门做分发点，源码与文档仍不外泄。

这与产品的「不建云」立场不冲突：此处仅托管更新元数据与安装包，
**不涉及任何用户数据**——行情、持仓、策略、券商 API Key 全程不出用户本机。

## 校验更新包

所有安装包都用 minisign 签名，公钥内置于应用中。应用会在安装前验签，
签名不匹配即拒绝安装。请只从本仓库的 Releases 页面下载。

## 反馈

- **GitHub**：本仓库 Issues 提供「Bug 反馈 / 功能建议」表单；应用内「这是什么？→ 反馈」与崩溃页「反馈此问题」按钮会打开预填好的 Issue，登录后提交即可。
- **Gitee（国内推荐）**：https://gitee.com/lzul/strathand-releases/issues —— 应用内反馈会把全文复制进剪贴板，粘贴到新建 Issue 提交即可。

本仓库只做更新分发，不接受 PR（无源码）；Issue 仅用于产品反馈。
